This project focused on predicting whether a driver would be involved in an accident using machine learning models on a limited dataset. Several explanatory variables were included in the analysis, including road conditions, weather, and driver experience. We compared six modeling approaches: logistic regression as a baseline, decision trees, random forests, neural networks, support vector machines (SVM), and gradient boosting. Models were evaluated using accuracy, precision, recall, F1-score, and ROC-AUC. The SVM had the lowest accuracy but achieved the highest recall and F1-score. We attributed the differences in model performance in part to class imbalance, as other models tended to predict the majority class.
